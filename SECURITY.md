# Security Policy

Thanks for helping keep the Saturday Morning Productions website safe.

This repository contains the source for the static site published at [https://saturdaymp.com](https://saturdaymp.com). Only the `main` branch is supported, since that is what gets built and deployed.

## Reporting a Vulnerability

Please do **not** open a public issue for a security problem. Instead, report it one of these ways:

- Go to the [Security tab](https://github.com/saturdaymp/saturdaymp.github.io/security)
  of this repository and choose "Report a vulnerability".
- Email [support@saturdaymp.com](mailto:support@saturdaymp.com).

Include steps to reproduce and the affected page or file if you know it.  We will get back to you as soon as we can and let you know when the issue is fixed.
